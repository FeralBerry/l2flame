Для получения 2 профессии каждому персонажу нужно иметь 2 марки в инвентаре, вторую из них вы можете уже получить сейчас.
Вторая марка классовая:
1. Для гладиатор, дестр, тир, копейщик, берс, физ ейтерия: Марка чемпиона. Квест называется "Испытание Доверия".
2. Для Паладин, ДА, ТК, ШК, МертвыйТанк: Марка доверия. Квест называется Испытание Доверия.
3. Для Некр, конь, кот, тень: Марка доверия. Квест называется Испытание Доверия.
4. Для сорк, СС, СХ, кам маг, маг ейтерия: Марка доверия. Квест называется Испытание Доверия.
5. Для ТХ, БХ, АВ, ПВ: Марка доверия. Квест называется Испытание Доверия.
6. Для хавк, Сыр, ФР, арба: Марка доверия. Квест называется Испытание Доверия.
7. Для Биш, ЕЕ, ШЕ, инспектор, овер: Марка доверия. Квест называется Испытание Доверия.
8. Для Проповедника, БД, СВС, крафт, варк: Марка доверия. Квест называется Испытание Доверия.

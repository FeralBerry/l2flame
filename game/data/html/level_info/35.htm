3. Для Тёмных Эльфов: Знак судьбы. Квест называется "Испытание судьбы".
4. Для Орков: Знак славы. Квест называется "Испытание славы".
5. Для Гномов: Знак Успеха. Квест называется "Испытание успеха".
6. Для Камаэлей: Знак Умения. Квест называется "Испытание умения".
7. Для Эйтерий: Знак Мудрости. Квест называется "Испытание мудрости".
